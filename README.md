# 🚴 Bike Sharing Data Analysis Dashboard

Interactive dashboard built with **Python** and **Streamlit** to analyze bike-sharing usage patterns.

## 📌 Overview

This project analyzes the Bike Sharing Dataset through exploratory data analysis (EDA) and presents the results using an interactive Streamlit dashboard.

## 📊 Analysis

The dashboard focuses on two analyses:

- **Bike Usage Based on Weather Conditions**
  - Bike rentals are highest during clear weather and decrease during cloudy and rainy conditions.

- **Bike Usage by Day of the Week**
  - Bike rentals are significantly higher on weekdays (Monday–Friday) than on weekends (Saturday–Sunday).

## 🛠️ Tech Stack

- Python
- Pandas
- Matplotlib
- Seaborn
- Streamlit

## 🚀 Run Locally

```bash
git clone https://github.com/eferdee/analisis-data-1.git
cd analisis-data-1
pip install -r requirements.txt
cd dashboard
streamlit run dashboard.py
```
